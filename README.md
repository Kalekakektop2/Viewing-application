# Viewing-application

**Windows-оверлей** для геймеров: выделил область экрана → Vision-ИИ подсказывает, что на скрине, как скрафтить и где найти — без Alt+Tab в Wiki.

Продуктовое описание и маркетинг: [Visual-gaming](https://github.com/Kalekakektop2/-Visual-gaming)  
**Полная спецификация приложения:** [docs/APP_SPEC.md](docs/APP_SPEC.md)

---

## Что делает

1. По горячей клавише (`Alt+E` по умолчанию, бинд настраивается) игрок выделяет **область** экрана.
2. Поверх игры появляется оверлей: строка ввода, кнопки «Что это?» / «Как скрафтить?» / «Где найти?», режимы **Кратко** / **Расширенно**.
3. Скрин + промпт уходят в vision-модель (цель — бесплатная, например Gemini). Ответ — текстом; опционально «Сгенерировать фото» с предупреждением о времени.
4. Можно продолжить **диалог** по тому же скрину. Закрытие — клик **вне** оверлея.
